# Fantastic Island v0.5.0

Fan module and island performance polish release.

This release turns the previous expanded Wind Drive area into a first-class Fan module, improves Codex expansion smoothness, refines the island Liquid Glass backplate, and adds source-side DMG packaging support.

## Highlights

- Added a dedicated Fan module with the shared fan animation state, logo settings, sound controls, and a Canvas-based airflow background
- Moved Fan-specific settings into the module settings surface and kept the main expanded island layout focused on selected module content
- Optimized the Codex token heatmap by drawing the grid with Canvas instead of hundreds of SwiftUI cell views
- Cached Codex token heatmap snapshots and throttled visually equivalent activity-state updates to reduce idle redraws
- Improved Codex token usage history handling with safer background scanning and history merging
- Kept the expanded island Liquid Glass surface visible during transitions while avoiding per-frame heavy glass relayout
- Tightened opened-content measurement so minor height changes do not repeatedly reposition the island during expansion
- Polished the X composer field layout, footer, focus styling, and validation presentation
- Added `scripts/create-dmg.sh` for local source-side DMG packaging and documented the current Finder install window layout
- Bumped the app marketing version to `0.5` and build number to `12`

## Notes

- This is still a `source-only` release. Prebuilt, signed, and notarized DMG artifacts are not included.
- The DMG packaging script creates an unsigned local installer image by default. Use your own signing and notarization flow before distribution.
- Existing users should see the new Fan module enabled automatically after the module list is migrated.
- Codex token history still depends on local Codex rollout JSONL files under the user's Codex sessions directory.

## Build

```bash
xcodebuild -project 'FantasticIsland/FantasticIsland.xcodeproj' -scheme 'FantasticIsland' -configuration Release CODE_SIGNING_ALLOWED=NO build
```

Create a local DMG:

```bash
scripts/create-dmg.sh
```

Lightweight logic tests:

```bash
swift test
```
