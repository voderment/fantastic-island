# Fantastic Island v0.4.0

Codex usage heatmap and X composer release.

This release adds a Codex token usage heatmap under the quota summary, improves Codex expansion performance, and ships the self-configured X/Twitter post module work that was staged locally before this release.

## Highlights

- Added a monochrome Codex tokens heatmap for daily usage over the last 365 days
- Added per-day hover tooltips with exact token counts
- Moved Codex token history scanning onto a background queue so live session updates are not blocked
- Tightened the Codex heatmap card layout and removed the unnecessary low/high legend
- Reduced Codex shortcut-open jank by deferring heavy expanded content mounting until the reveal phase
- Skipped hidden closed-state premeasurement for the Codex expanded view to avoid building heavy Codex content offscreen
- Added the self-configured X/Twitter post module and polished the composer, settings, focus, shortcut, alignment, and resizing behavior

## Notes

- This is still a `source-only` release.
- Codex token history is read from local Codex rollout JSONL files under the user's Codex sessions directory.
- The first Codex heatmap refresh may arrive shortly after the live session list because historical token scanning is asynchronous.
- The X/Twitter module requires user-provided API credentials.

## Build

```bash
xcodebuild -project 'FantasticIsland/FantasticIsland.xcodeproj' -scheme 'FantasticIsland' -configuration Release CODE_SIGNING_ALLOWED=NO build
```

Lightweight logic tests:

```bash
swift test
```
